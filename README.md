# Nicole Pilli - portfolio website

Plain HTML, no build step.

- `index.html` - home page
- `parallel-studios.html` - Parallel Studios project page
- `rbc.html` - RBC Royal Bank of Canada project page

## Deploy on Cloudflare Pages
1. Push this folder to a GitHub repository.
2. Cloudflare dashboard -> Workers & Pages -> Create -> Pages -> Connect to Git -> pick the repo.
3. Build command: leave empty. Build output directory: leave empty (or `/`). Deploy.
4. In the Pages project open Custom domains -> add `nicole.pilli.info`.
